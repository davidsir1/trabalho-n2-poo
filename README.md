# Sistema de Adoção

Trabalho da disciplina Programação Orientada a Objetos e consiste em um sistema de adoção desenvolvido em Java e JavaFX.
O sistema possui funcionalidades de gestão de animais e baias e registro de adoção.

# Configuração

Arquivo de configuração de ambiente:

```dotenv
URL=jdbc:mysql://ip:porta/banco_de_dados
USER=
PASS=
```

# Tecnologias Utilizadas

- JDBC
- JavaFX 21
- Java 25
- [AtlantaFX](https://github.com/mkpaz/atlantafx)
- [Scene Builder](https://gluonhq.com/products/scene-builder/)
