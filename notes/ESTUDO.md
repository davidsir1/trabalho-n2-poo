# Criptografia

AES (Advanced Encryption Standard) é uma cifra debloco sucessora do DES (Data Encryption Standard), usa o algoritmo
de Rijndael, que envolve a subsstituição de permutação para criar dados criptografados de uma mensagem. Ele opera
sobre um arranjo bidimensional de bytes com 4x4 posições.
